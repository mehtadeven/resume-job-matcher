How it works

The same steps as matcher.py, ported line by line to JavaScript.

  1. Rank the job's terms. TF-IDF weights every word in the job post; common filler words are dropped.
  2. Keep the top 15. The highest-weighted terms become the keywords a screener would look for.
  3. Check the resume. Each keyword is marked found or missing.
  4. Score the overlap. Cosine similarity of the two TF-IDF vectors gives a second, overall score.

Run the Python version: pip install -r requirements.txt then python matcher.py sample_resume.txt sample_job.txt. The sample gives 46.7% (7 of 15) in both versions.
